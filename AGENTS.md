# Student Living

React + Vite + Tailwind CSS application for student accommodation discovery and management.

- `src/main.tsx` — React entrypoint
- `src/App.tsx` — application shell
- `src/index.css` — Tailwind CSS and global styles
- `src/components/` — shared UI components
- `src/pages/` — route pages
- `src/routes/` — application routing
